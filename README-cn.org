* API Document

本项目按 Spring Boot 大版本分别维护, ~master~ 分支只用于项目说明, 不包含可发布代码.

| 分支 | Spring Boot | 当前版本 | 说明 |
|------+-------------+----------+--------|
| [[https://github.com/liuanxin/api-document/tree/springboot2][springboot2]] | 2.x | 2.1.2 | Java 8 |
| [[https://github.com/liuanxin/api-document/tree/springboot3][springboot3]] | 3.x | 3.1.2 | Java 17 |
| [[https://github.com/liuanxin/api-document/tree/springboot4][springboot4]] | 4.x | 4.1.2 | Java 17 |

请进入与项目 Spring Boot 大版本对应的分支查看完整 README、源码和维护说明.

Maven 坐标:
#+BEGIN_SRC xml
<dependency>
    <groupId>io.github.liuanxin</groupId>
    <artifactId>api-document</artifactId>
    <version>对应分支的当前版本</version>
</dependency>
#+END_SRC
